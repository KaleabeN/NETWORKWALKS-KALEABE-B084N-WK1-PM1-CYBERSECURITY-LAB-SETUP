# 🛡️ SOC Analyst Wireshark Project Module

Welcome to my Wireshark SOC Lab repository! This project contains my hands-on work from a series of live browser-based SOC (Security Operations Center) analyst labs. The goal was to simulate real-world network traffic investigations, identify threat actors, and extract actionable intelligence from packet captures (PCAPs).

## 🎯 Project Mission
Acting as a SOC Analyst, I investigated multiple network captures to identify attackers, uncover hidden data, find plain-text passwords, detect brute-force attacks, and investigate a VoIP scam call.
