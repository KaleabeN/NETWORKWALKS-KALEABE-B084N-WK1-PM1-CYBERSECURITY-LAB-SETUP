# Week 3: Password Auditing & Cryptographic Recovery

## 📌 Project Overview
This folder contains the final report and evidence for Week 3 of the Cybersecurity & Ethical Hacking program at Networkwalks. The focus this week shifted to **Password Auditing and Cryptographic Recovery**. 

The objective was to demonstrate how weak passwords can be rapidly compromised, emphasizing the critical need for strong passphrases and Multi-Factor Authentication (MFA) in organizational security.

## 🛠️ Tools & Technologies Used
*   **Kali Linux (VMware):** Virtualized environment used for offline auditing.
*   **John the Ripper (Johnny GUI):** Industry-standard password recovery tool used to execute dictionary attacks.
*   **Networkwalks Hash Calculator:** Custom web tool used to extract cryptographic hashes from a protected PDF.
*   **Networkwalks Password Cracker:** Custom web tool used for streamlined credential recovery.

## 📂 Modules Completed
1.  **W3-PM1:** Password Cracking with JTR (Executed via Kali Linux in VMware).
2.  **W3-PM2:** Password Cracking with Networkwalks Web Tools.
