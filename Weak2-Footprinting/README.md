# Week 2: Footprinting & Reconnaissance Attacks

## 📌 Project Overview
This folder contains the final report and evidence for Week 2 of the Cybersecurity & Ethical Hacking program at Networkwalks. The project focuses on Phase 1 of the penetration testing lifecycle: **Footprinting and Reconnaissance**, followed by **Network Scanning**.

The objective was to gather publicly available information (OSINT) without alerting the target, identify accidentally exposed assets on the internet, and map a local network infrastructure.

## 🛠️ Tools & Technologies Used
*   **Kali Linux & Windows OS**
*   **Multi-Tool Recon:** WHOIS, WhatWeb, Nslookup, Curl, Wafw00f, DNSRecon
*   **Google Hacking Database (GHDB) / Exploit-DB:** Google Dorking for exposed devices and directories
*   **Maltego:** OSINT graphical link analysis
*   **theHarvester:** Email and subdomain harvesting
*   **Zenmap (Nmap GUI):** Local network discovery and topology mapping

## 📂 Modules Completed
1.  **W2-PM1:** Footprinting with Multiple Kali Tools (`networkwalks.com`)
2.  **W2-PM2:** Footprinting with GHDB (Finding exposed cameras and open directory PDFs)
3.  **W2-PM3:** Footprinting with Maltego (Email harvesting)
4.  **W2-PM4:** Footprinting with theHarvester (`microsoft.com`)
5.  **W2-PM5:** Network Scanning with Zenmap (Local LAN)
